# 私有 AI 知识库 Starter｜仅含空白模板

⚠️ **注意：你现在看到的 starter 位于公开仓库；里面只有空白模板，不包含任何私密数据。**

本目录不是私人保险库！请**不要直接在这里填写真实私人资料或客户内容**。

## 目标

在 GitHub 中另建一个 **Private** 仓库，例如 `my-ai-vault`，专门存放不适合公开的职业资料、个人学习记录与 AI 协作上下文。

## 建议的精简目录

```text
my-ai-vault/                     # 必须是独立 Private 仓库
├── README.md                    # 使用边界与索引
├── 01-profile/
│   └── personal-profile.md      # 个人背景、方向、优先级；按需填写
├── 02-projects/
│   └── project-template.md      # 一个项目一个文件；权限检查
├── 03-learning/
│   └── learning-log.md          # 学习主题、案例、实践与复盘
└── 04-decisions/
    └── decision-log.md          # 重要决策、理由、结果
```

从本目录复制以下空白模板使用：
- [个人档案](PRIVATE_PROFILE_TEMPLATE.md)
- [项目记录](PROJECT_RECORD_TEMPLATE.md)
- [学习与成长记录](LEARNING_LOG_TEMPLATE.md)
- [决策记录](DECISION_LOG_TEMPLATE.md)

## 创建指引（仓库必须私有）

1. 打开 [GitHub 新建仓库](https://github.com/new)，仓库名称填写 `my-ai-vault`（或自行命名）。
2. **Visibility 选择 Private**；建议勾选添加 README。
3. 创建后检查仓库页面是否显示 **Private** 标识。
4. 将本目录的**模板内容**复制到新仓库对应位置，之后只在新仓库填写具体记录。
5. 需要 AI 协助管理时，先确认 GitHub 连接/应用有权访问这个私有仓库；否则 AI 可能看不到。
6. 绝不将私有内容通过 PR、Issue、Pages 或复制粘贴泄漏到公开仓库。

## 权限与保密提醒

Private ≠ 仅有本人能看；仓库协作者、被授权的 GitHub App 等仍可能访问。合同原件、身份证明、账号密钥、供应商隐私、客户高度敏感资料建议继续使用更适当的受控存储，不必存入 GitHub。

## 与公开档案如何分工

- **公开档案**：职业定位、工作习惯、可公开的方法论。
- **私有档案**：真实项目复盘、本人职责细节、学习进展、长期目标与决策记录。
- **临时项目文件**：有客户授权边界和保密要求的资料，可独立存于项目指定位置，不必全部汇总到个人档案。
