# AI 工作流｜按任务选择，不要套一个模板解决所有问题

这是个人工作偏好，具体步骤可以按项目规模删减；不要把下面的框架当作不可变规则。

## A｜创意活动策划

**输入**：Brief、项目背景、目标受众、交付时间、场地及预算约束。

**输出顺序**：
1. **一页策略简报**：目标 / 受众 / 真实障碍 / 核心矛盾 / 成功指标 / 限制条件；
2. **事实分层**：客户已确认 / 来源可验证 / 推测假设 / 待确认；
3. **案例研究**：国内 + 国际的真实案例，附可查来源与机制拆解；
4. **三条创意路线**：每条必须在参与者角色、任务、互动规则或故事结构上有本质区别；
5. **优选路线的内容系统**：核心观点、议题、人物故事、现场环节与可留存成果；
6. **体验落地**：流程、空间动线、节目、互动装置、物料、工作人员、风险、成本假设；
7. **提案与质检**：逐页逻辑、讲标话术、反对意见、易错点。

**不合格征兆**：只有几个 Slogan、几个打卡区、好看的海报；没有人为什么参与、执行资源或活动后结果。

## B｜PPT / 主视觉 / 物料

**先检查四件事**：原始素材 / 保留元素 / 允许修改的范围 / 验收标准。

流程：内容与版式结构 → 选 1–3 页预览方向 → 视觉定稿 → 批量延展 → 输出可编辑文件 → 检查中文、比例、清晰度与元素一致性。

**质量底线**：
- 图像与 Logo 不得在未经确认的情况下替换、重绘或失真；
- 没有能力提供真实可编辑文件时，明确说明并交付可用的底图或源资产；
- 不用单一母版机械复制所有页面。

## C｜案例分析与系统学习

对案例回答：谁办的、什么时候、目标是什么、参与者做了什么、为什么有效（有证据或明确标注假设）、哪些可以借鉴、哪些不应照搬。

把案例拆成**可迁移的机制**，不要只收集美图与主题。

## D｜报价、执行和复盘

- **报价**：区分采购成本、服务费、税费、损耗、风险预留与利润假设；单位、数量、单价和合计必须可核对。
- **执行**：关键路径、责任人、现场节点、联动条件、应急预案。
- **复盘**：预期/实际、证据、原因、可复用改进，下次行动与负责人。
- 不将估算值当成已发生的结果。

## E｜作品集与职业成长

作品集不只展示视觉，要写清：**项目问题 → 本人承担的职责 → 核心决定 → 方案机制 → 执行难点 → 可核实的结果/反思**。

外部公开前核查客户授权、照片版权、人员肖像、内部预算和商务敏感信息。若无法公开，采用匿名且不具有可识别性的改写。

## 三层工作产物

1. **过程资产**：研究、对比、假设、方案草稿（一般不公开）。
2. **项目资产**：定版方案、流程、物料、执行与复盘（按客户权限管理）。
3. **可公开成果**：经核准的案例摘要、作品集、方法论（可放此仓库）。

## 每次对话结尾的建议

- 当前结论与已完成事项；
- 哪些是确认事实，哪些仍是猜测；
- 最重要的 1–3 个待办；
- 是否需要将新偏好或方法更新到个人档案（须经用户确认，不自动公开）。
