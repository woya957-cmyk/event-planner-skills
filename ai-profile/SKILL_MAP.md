# 能力地图｜职业发展与学习方向

> 这是**自我管理的能力框架**，不是官方资格认证或已验证的项目业绩。能力状态应根据具体工作案例持续更新。

| 能力领域 | 关注点 | 下一步积累的证据 |
| --- | --- | --- |
| 需求洞察与策略 | 从 Brief 提炼核心问题、受众行为障碍 | 策略一页纸、客户反馈 |
| 内容创意与故事设计 | 内容议题、人物、戏剧性节奏 | 机制设计、节目内容、真实故事 |
| 体验与互动机制 | 用户行为、游戏规则、反馈与留存 | 参与流程、测试与复盘 |
| 现场执行与项目统筹 | 进度、供应商、物料、人流、应急 | 时间表、职责矩阵、风险清单 |
| 视觉与提案表达 | Keynote/PPT 讲标、主视觉、空间表达 | 可编辑作品、讲标结构 |
| AI 辅助工作 | 研究、结构化、批判审查、资产沉淀 | 可重复使用的流程、质量提升证明 |
| 大型演出/综艺化现场 | 节目统筹、视听叙事、现场戏剧节奏 | 后续有证据的项目经历 |

## 个人成长方向

重点探索：
1. 从活动方案制作升级到**以内容策略为核心的创意策划**；
2. 系统研究大型演出、综艺节目结构与参与式体验；
3. 用真实项目证据建立具有个人判断和方法论的作品集；
4. 将 AI 作为研究、构思、质量审查和知识组织的工具，而不是替代独立思考。

## 评价方法

针对每一项能力，补充：
- **证据**：本人承担的任务 / 案例链接 / 可验证成果；
- **独立程度**：协助 / 共同负责 / 独立负责；
- **复盘**：做对了什么、下一次改变什么；
- **下一步**：未来 30–90 天可以完成的实践。

未核实的评分不要写成「专家」「精通」或虚构 KPI。

## 更新节奏

每个重要项目结束后更新一次；每季度重新审视职业方向和技能短板。敏感原始证据只存储于有适当访问控制的位置。
