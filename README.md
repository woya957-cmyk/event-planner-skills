## 使用方式

1. **ChatGPT/其他 AI**：提供 QUICK_CONTEXT 的链接或复制内容，确认工具能实际读取后开始工作。
2. **活动策划**：让 AI 按 WORKFLOWS 对 Brief 拆解，针对参与机制产生不同创意路线。
3. **提案交付**：使用 QUALITY_CHECKLIST 检查内容、现场执行与可编辑文件。
4. **完成项目**：在具备合法公开授权的前提下，用 CASE_TEMPLATE 沉淀可公开的成果；私有内容仅存独立 Private 仓库。

> 仓库中的方法论属于协作偏好，不会自动成为所有 AI 服务的永久记忆；当前项目的明确需求和最新事实始终优先。
